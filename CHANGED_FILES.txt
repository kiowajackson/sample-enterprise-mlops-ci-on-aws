S3 folder configuration
-----------------------
Set "s3_prefix": "mlops" in notebooks/config.json, or inherit that default from
the updated template. New application writes use:
    s3://<bucket>/<s3_prefix>/<namespace>/...
Nested parent folders are supported. Namespace still identifies the pipelines
and Registry scope. Restart the kernel and republish notebook 02 after copying
the changed source; existing published definitions retain their old paths.

SHAP diagnostics and temporary workaround
-----------------------------------------
  mlops-models/scratch/inspect_shap_base_score.py
  mlops-models/scratch/shap_xgboost_workaround.py

The diagnostic prints versions, the actual model class and raw XGBoost base_score.
The temporary workaround runs only for an actual XGBoost Booster. It converts
one finite vector-form intercept in SHAP's decoded dictionary, preserving the
Booster and its predictions. It is restricted to SHAP 0.49.1 and single-output
models. Paste the whole block before the existing TreeExplainer call. Remove it
when the platform provides a compatible, validated image. LightGBM keeps its
existing explanation path.
