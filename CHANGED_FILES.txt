CONFIGURATION
Set tracking_uri in the existing notebooks/config.json to the approved MLflow
Tracking Server or App ARN. Keep the other config values. No new keys are needed.
An empty tracking_uri disables tracking.

Notebook 02 uses the installed MLflow client to verify a labelled connection-check
run, parameters, metrics, tags, dataset reference, run search and artifact
upload/download in each model experiment. Experiment names and artifact locations
are derived without extra inputs. Client/server versions are diagnostic values.

The notebook and jobs use their provided clients; this update removes the exact
version rejection and notebook-to-job version requirement. It does not install
packages, change requirements or rebuild images. Actual API or access errors
remain visible. Inference uses its selected Registry package's existing image.

VALIDATION

local MLflow 3.0.0 HTTP server, including dataset references and artifact readback.

human UI access still need verification in the receiving environment.
