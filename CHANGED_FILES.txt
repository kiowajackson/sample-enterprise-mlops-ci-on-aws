Notebook 02 defaults to model_code_source="pipeline", batch_runtime="processing",
cache_steps=True. Keep your notebooks/config.json, restart the notebook kernel,
and Run All. It publishes the pipelines; then execute inference for the approved
ModelId with the intended scoring CsvInputUri. It does not start jobs automatically.
No training rerun is needed for a compatible existing model with saved metadata.

KEEP YOUR WORKING CUSTOM TRAINER. The generic model_base/training/train.py change
only adds feature_mapping and predictor_path="predictor" to its demo metadata.
An adapted trainer that saves its feature_mapping and root AML.path checkpoint
can remain as it is. Metadata already travels inside registered model.tar.gz.

The prediction file hook gets a local CSV, the saved mapping, primary key and
registered checkpoint. Port the model-specific transformations/loading into the
ModelPredictor class. Return primary key + numeric score, one row per input.
Mapping is input-column -> model-column, exact case. Messaging/multiclass output
needs a model-specific adapter. See README for the full contract.
